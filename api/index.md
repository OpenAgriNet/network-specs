# API specifications

[Provider HTTP contracts](external/) describe what a caller sends to the upstream service and what it receives. Start there for paths, field names and examples.

[Adapter proposals](adapter/) describe a different boundary: payloads a network consumer and an adapter could exchange. They are not evidence of a provider endpoint. The [provider walkthrough](../schema/examples/providers/) connects the two where a binding is known.
