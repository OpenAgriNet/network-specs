Direct and OnDemand

For a Direct resource, the record is already in the discovery result. Reading that record needs no follow-up action. An OnDemand resource advertises what the provider can return or do. The client uses an advertised action to get the result or start the workflow.

The registry and catalog answer different questions. The catalog advertises what the provider offers. The registry binds actions to handlers. Native operation links below identify upstream HTTP contracts, not network action endpoints.
